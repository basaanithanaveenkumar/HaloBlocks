Abstract

Architecture research repeatedly re-implements the same layers with slightly different interfaces that make them hard to swap. HaloBlocks is a small PyTorch library, published on PyPI, in which every component is a Block registered under its class name and can be created directly, by name, or from a nested configuration dictionary.

It ships 37 registered blocks: attention variants from scaled dot-product to multi-head latent attention with the absorption trick and QK-normalised output-gated Trinity attention; sinusoidal, learned, rotary and ALiBi positions; a configurable MLP; DeepSeek-style mixture-of-experts; transformer blocks and decoders; and a flow-matching action decoder for VLA models. A TransformerBlockBuilder assembles a layer from any registered attention, cross-attention and feed-forward blocks with a declarative operation order.

Highlights

Three ways, one object

blocks.X(...), hb.create('X', ...) and hb.create({'type': 'X', ...}) return the same block.

Attention zoo

SDPA, MHA, MQA, GQA, cross, gated, sliding-window (dilated, dynamic), linear (ELU/ReLU/Exp, RoPE), MLA and Trinity.

Builder

Any attention + optional cross-attention + any FFN, with PRE_NORM, POST_NORM or *_CROSS orders and LayerNorm or RMSNorm.

Config-driven

Nested dicts build whole models through CompositeBlock, so they are YAML/JSON-serialisable and easy to sweep.

MoE and VLA

DeepSeek MoE (shared + noisy top-k routed) and a flow-matching FlowActionDecoder.

Released properly

71 tests; merging a release PR tags the version and publishes it to PyPI.

Known inconsistencies (v0.1.3)

The README describes TrinityAttention as local + global + linear, but the code is QK-normed softmax attention with a sigmoid output gate. The builder's string form ffn='DeepseekMoE' with ffn_kwargs fails (use the dict form). The README's CI badge points to a missing workflow.

Quick start

pip install haloblocks        # or: uv add haloblocks
import torch, haloblocks as hb

layer = hb.create("TransformerBlockBuilder", emb_dim=256, norm="rmsnorm",
    attn={"type": "GroupedQueryAttention", "num_heads": 8, "num_kv_heads": 2},
    ffn={"type": "DeepseekMoE", "emb_dim": 256, "hid_dim": 512,
         "num_router_exprts": 8, "best_k": 2, "num_shared_exprts": 1})
y = layer(torch.randn(2, 16, 256))       # (2, 16, 256)
